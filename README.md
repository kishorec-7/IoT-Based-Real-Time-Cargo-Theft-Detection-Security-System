# IoT-Based Real-Time Cargo Theft Detection & Security System

## Overview
The IoT-Based Real-Time Cargo Theft Detection & Security System is designed to enhance cargo transportation security by continuously monitoring cargo conditions and detecting unauthorized access during transit. The system employs a Master Node–Child Node architecture to provide real-time monitoring, location tracking, and instant alerts, helping reduce cargo theft and improve logistics safety.

## Features
- Real-time cargo monitoring
- Unauthorized door opening detection
- Lock tampering detection
- Cargo movement and displacement detection
- Human presence detection inside cargo
- GPS-based live location tracking
- Instant alert notifications
- Master Node–Child Node communication architecture

## Tech Stack
